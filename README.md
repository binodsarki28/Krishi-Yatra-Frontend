Project Overview
The interactive frontend for KrishiYatra, providing a seamless marketplace experience for farmers and consumers with real-time tracking and notifications.


Core Features

Role-based dashboards with PrimeNG UI components
Interactive Leaflet maps for order tracking and address pinning
Real-time push notifications receiver using Firebase
Responsive marketplace with category and sub-category filtering
Dynamic KYC and profile management systems



Technology Stack

Angular, RxJS, PrimeNG
Leaflet.js, Firebase Messaging



Setup Instructions

Clone the repository.
Run npm install to install dependencies.
Add Firebase configuration in environment.ts.
Run ng serve
